## Return statement

The `return` statement in Python immediately **exits a function and sends a specific value back** to the line of code that called it.

Without `return`, a function processes data but cannot pass the result back to the rest of your program.

**Example:**
```run-python
# 🚫 WITHOUT RETURN: The result is trapped inside the function
def add_numbers(a, b):
    result = a + b

output = add_numbers(5, 3)
print(output)  # Output: None (The result was lost)


# ✅ WITH RETURN: The result is sent back and can be stored
def add_numbers(a, b):
    return a + b

output = add_numbers(5, 3)
print(output)  # Output: 8

```

## Key Components of Python Functions

- **Arguments & Parameters**: Parameters are variables listed in the function definition. Arguments are the actual values sent to the function when called.

- **Return Values**: Functions use the `return` statement to send data back to the caller. If no return is specified, it implicitly returns `None`.

- **Default Parameters**: You can assign default values to parameters if an argument is omitted during the call.

**Example:**
```run-python
# Function with a default parameter and a return value
def calculate_total(price, tax=0.05):
    return price + (price * tax)

# Calling with one argument (uses default tax)
print(calculate_total(100))  # Output: 105.0

# Calling with both arguments (overrides default tax)
print(calculate_total(100, 0.10))  # Output: 110.0

```

# Global vs Local Variables

In Python, where you create a variable determines where you can use it. This concept is called **variable scope**. 

- **Local Variables**: Created _inside_ a function. They only exist while that function is running and cannot be accessed from outside.

- **Global Variables**: Created _outside_ all functions. They exist across your entire script and can be read from anywhere.

**Example:**
```run-python
x = "Global"  # Global variable (visible everywhere)

def my_function():
    y = "Local"  # Local variable (visible ONLY inside this function)
    print(y)     # ✅ Works
    print(x)     # ✅ Works (Functions can read global variables)

my_function()

print(x)         # ✅ Works
print(y)         # ❌ NameError: name 'y' is not defined (Outside its scope)
****
```

## Modifying Global Variables

By default, Python allows you to **read** global variables inside a function, but if you try to **modify** them, Python will accidentally create a new local variable with the same name instead.

To modify a global variable inside a function, you must use the `global` keyword. 

❌ The Common Mistake (Without `global`)
```run-python
counter = 0

def increment():
    counter = 5  # Creates a NEW local variable; does NOT change the global one

increment()
print(counter)  # Output: 0

```

✅ The Fix (With `global`)
```run-python
counter = 0

def increment():
    global counter  # Tells Python to use the global variable
    counter = 5     # Changes the global variable

increment()
print(counter)  # Output: 5

```
