# Error and Exceptions

## Python Syntax Errors

These occur when your code violates the official grammar rules of Python. The Python interpreter catches these mistakes _before_ it runs any part of the program.

- **SyntaxError**: Raised when code formatting is invalid, such as missing a colon or unclosed parentheses.
- **IndentationError**: A subclass of `SyntaxError` that happens when spaces or tabs do not align correctly.

```python
# SyntaxError: missing the closing parenthesis
print("Hello World"

# IndentationError: missing block indentation
if True:
print("Oops")
```

## Exceptions

## `NameError`

- Raised when you try to use a variable or function name that has not been defined or is out of scope.

- **Example:** `print(my_var)` (if `my_var` wasn't created first).

- **Fix:** Ensure the variable is declared, check for typos, or make sure it is defined in the correct scope.

## `TypeError`

- Raised when an operation or function is applied to an object of the inappropriate data type.

- **Example:** `print("Hello" + 5)` (you cannot concatenate a `string` and an `integer`).

- **Fix:** Convert the data types explicitly (e.g., `print("Hello" + str(5))`) before performing the operation.

## `ValueError`

- Raised when a function receives an argument of the correct type but an inappropriate value.

- **Example:** `int("abc")` (the type is correct, but `"abc"` cannot be converted to an integer).

- **Fix:** Validate the data before processing it, or check the documentation to ensure the value falls within accepted parameters. 

## `ZeroDivisionError`

- Raised when you attempt to divide a number or variable by zero.

- **Example:** `10 / 0` or `10 % 0`.

- **Fix:** Add a check to ensure the denominator is not equal to zero before running the division logic.

# Handling Exception

The `try` block lets you test a block of code for errors.

The `except` block lets you handle the error.

The `else` block lets you execute code when there is no error.

The `finally` block lets you execute code, regardless of the result of the try- and except blocks.
## Try-except Block

When an error occurs, or exception, Python will normally stop and generate an error message.

These exceptions can be handled using the `try` statement:

```run-python
try:
  print(x)
except:
  print("An exception occurred")
```

Since the try block raises an error, the except block will be executed.

Without the try block, the program will crash and raise an error.

## Many Exceptions

```run-python
try:
    # This raises a NameError because 'x' has not been defined yet
    print(x)

except NameError:
    # Git catches the NameError specifically, so this block runs
    print("Variable x is not defined")  # OUTPUT: Variable x is not defined

except:
    # This is a fallback block. It is skipped because the NameError was already caught above
    print("Something else went wrong")
```

## Else

You can use the `else` keyword to define a block of code to be executed if no errors were raised:

```run-python
try:
    # This runs successfully because printing a string doesn't cause any errors
    print("Hello")  # OUTPUT: Hello

except:
    # This block is skipped because NO errors occurred in the try block
    print("Something went wrong")

else:
    # This block runs ONLY if the try block executes without any errors
    print("Nothing went wrong")  # OUTPUT: Nothing went wrong
```

## Finally

The `finally` block, if specified, will be executed regardless if the try block raises an error or not.
```run-python
try:
    # This will raise a NameError because 'x' is not defined
    print(x)

except:
    # Because an error occurred in the try block, this block runs
    print("Something went wrong")  # OUTPUT: Something went wrong

finally:
    # This block ALWAYS runs, regardless of whether an error happened or not
    print("The 'try except' is finished")  # OUTPUT: The 'try except' is finished
```

# Raising Exceptions

The `raise` keyword is used to raise an exception.

You can define what kind of error to raise, and the text to print to the user.

```run-python
x = "hello"  
  
if not type(x) is int:  
  raise TypeError("Only integers are allowed")
```

**Output**

```python
Traceback (most recent call last):
  File "script.py", line 5, in <module>
    raise TypeError("Only integers are allowed")
TypeError: Only integers are allowed
```

# User Defined Exceptions

```run-python
class MyError(Exception):
	def __init__(self,value):
		self.value = value
	def __str__(self):
		return str(self.value)

try:
	raise MyError(2*2)
except MyError as e:
	print('Value:', e) #returns Value: 4

raise MyError('Oops!') #raises an error
```
