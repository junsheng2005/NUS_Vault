# Dimensions in Python

1-Dimensional Array
- Each element can be identified with 1 value
- Can be implemented as a list

2-Dimensional Array
- Each element can be identified with 2 values
- -Can be implemented as a list of lists

n-Dimensional Array
- Each element can be identified with n values
- Can be implemented as a list of lists of ... of lists

# 2-D Array

## Creating Zero Matric

```python
def create_zero_matrix(row, col):
	res = [[0]*col for i in range(row)]
```

## 2D Looping

### Loop by Element
```run-python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Outer loop tracks each row
for row in matrix:
    # Inner loop tracks each element in that row
    for item in row:
        print(item, end=" ")
# Output: 1 2 3 4 5 6 7 8 9

```

### Loop by Index

```run-python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

# Loop through row indices
for r in range(len(matrix)):
    # Loop through column indices of the current row
    for c in range(len(matrix[r])):
        # Modify elements (for example, double the values)
        print(matrix[r][c])

```

## 2D Array Applications

### Adding Matrices

```python
def matrix_add(m1, m2):
    # Assume m1, m2 have same row, col
    row, col = len(m1), len(m1[0])
    res = create_zero_matrix(row, col)
    for i in range(row):
        for j in range(col):
            res[i][j] = m1[i][j] + m2[i][j]
    return res
```

## Quiz 2

You are given a 2-D integer array L implemented using a list of lists. You are also given a 1-D integer array K implemented as a list. Write a function `isLinear(L,K)`, which will return true if K is a **linearization** of L, and false otherwise

A **linearization** of a 2-D array is to take each row of the 2-D array and concatenate them from row 0 to the last row to form a 1-D array.

Example:

`L = [[1,2,3],[4,5,6],[7,8,9]]`, `K = [1,2,3,4,5,6,7,8,9]`

`isLinear(L,K)` should return `True` since K is a linearization of L

>[!example]- Answer
> 
> ```run-python
> def isLinear(L,K):
>     l1 = []
>     for i in L:
>         for j in i:
>             l1.append(j)
> 
>     return l1 == K
> 
> L = [
> [1,2,3],
> [4,5,6],
> [7,8,9]
> ]
> 
> K = [1,2,3,4,5,6,7,8,9]
> 
> print(isLinear(L,K))
> ```
