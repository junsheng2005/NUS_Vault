# Set

In Python, a **`set`** is a built-in data structure used to store an **unordered collection of unique elements**. Sets are mutable, allowing you to add or remove items, but they automatically filter out any duplicate values and do not track the order of elements

## Basic Syntax

```run-python
# Creating a set with elements
fruits = {"apple", "banana", "cherry", "apple"} 
print(fruits)  # Output: {'banana', 'cherry', 'apple'} (Duplicates are auto-removed!)

# Creating an empty set (Must use set(), since {} creates an empty dictionary)
empty_set = set() 

# Converting a list with duplicates into a unique set
numbers = set([1, 2, 2, 3, 4, 4]) 
print(numbers) # Output: {1, 2, 3, 4}
```


## Operations to Check Set Properties

- **`len(set)`**: Returns the total number of unique elements inside the set.

- **`min(set)`**: Returns the smallest element. Throws a `ValueError` if the set is empty unless a `default` parameter is passed.

- **`max(set)`**: Returns the largest element. Throws a `ValueError` if the set is empty unless a `default` parameter is passed.

- **`item in set`**: Returns `True` if the item exists in the set, otherwise `False`.

- **`item not in set`**: Returns `True` if the item does not exist in the set, otherwise `False`. 

```run-python
# Initialize a set
my_set = {10, 20, 30, 40}

# 1. Size / Length
print(len(my_set))      # Output: 4

# 2. Extrema / Limits
print(min(my_set))      # Output: 10
print(max(my_set))      # Output: 40

# 3. Membership
print(20 in my_set)     # Output: True
print(50 not in my_set) # Output: True
```
## Modifying Elements

- **Add items**: Use `.add()` for a single element, or `.update()` to add multiple items from another collection.

- **Remove items**: Use `.remove()` (raises an error if the item does not exist) or `.discard()` (fails silently if the item is missing).

```run-python
my_set = {1, 2, 3}

my_set.add(4)             # {1, 2, 3, 4}
print(my_set)

my_set.update([5, 6])     # {1, 2, 3, 4, 5, 6]
print(my_set)

my_set.remove(2)          # {1, 3, 4, 5, 6}
print(my_set)

my_set.discard(99)        # Does nothing (no error)
print(my_set)
```

## Mathematical Operations

| Operation           | Method Syntax               | Operator Syntax | What it does                                       |
| ------------------- | --------------------------- | --------------- | -------------------------------------------------- |
| **Union**           | `a.union(b)`                | a \| b          | Combines elements from both sets.                  |
| **Intersection**    | `a.intersection(b)`         | `a & b`         | Keeps only items present in both sets.             |
| **Difference**      | `a.difference(b)`           | `a - b`         | Keeps items in `a` that are not in `b`.            |
| **Symmetric Diff.** | `a.symmetric_difference(b)` | `a ^ b`         | Keeps items unique to each set (omits duplicates). |

set_a = {1, 2, 3}
set_b = {3, 4, 5}

print(set_a & set_b)  # Output: {3}

# Dictionary
A **Python dictionary** is a built-in, mutable data structure that stores data in **ordered key-value pairs**, where each unique key maps to a specific value.

- **Key-Value format**: Items are stored as `key: value` pairs enclosed in curly braces `{}`.

- **Ordered**: Starting with Python 3.7, dictionaries maintain the exact insertion order of items.

- **Unique Keys**: Duplicate keys are not allowed. Assigning a new value to an existing key overwrites its previous value.

- **Key Restrictions**: Keys must belong to an immutable data type (like strings, numbers, or tuples).

- **Flexible Values**: Values can be of any data type, including lists, objects, or even other dictionaries.

## Basic Syntax

```run-python
# Empty dictionary
user_info = {} 

# Dictionary with initial data
user_info = {
    "username": "coder123",
    "email": "coder123@example.com",
    "login_count": 5
}
```

## Accessing Values

You can fetch data using brackets `["key"]` or the `.get()` method.

```run-python
user_info = {
    "username": "coder123",
    "email": "coder123@example.com",
    "login_count": 5
}

# Bracket notation (Raises KeyError if key does not exist)
print(user_info["username"])  # Output: coder123

# Safe access (Returns None or a default value if key is missing)
print(user_info.get("status", "Inactive"))  # Output: Inactive
```

## Adding and Modifying Items

```python
# Modifying an existing key
user_info["login_count"] = 6

# Adding a completely new key
user_info["is_active"] = True
```

## Removing Items

You can remove items using the `del` keyword or the `.pop()` method, which isolates and returns the removed value.

```python
# Remove and get the value
deleted_email = user_info.pop("email")

# Delete an item without returning it
del user_info["login_count"]
```

## Iterating Through Dictionaries

```run-python
user_info = {
    "username": "coder123",
    "email": "coder123@example.com",
    "login_count": 5
}

# Loop through keys and values simultaneously
for key, value in user_info.items():
    print(f"{key}: {value}")

# Loop through keys only
for key in user_info.keys():
    print(key)

# Loop through values only
for val in user_info.values():
    print(val)
```

## Essential Dictionary Methods

| Method               | Action Summary                                                                    |
| -------------------- | --------------------------------------------------------------------------------- |
| `.clear()`           | Removes all elements from the dictionary.                                         |
| `.copy()`            | Returns a shallow copy of the dictionary.                                         |
| `.get(key, default)` | Safely returns the value of the specified key.                                    |
| `.items()`           | Returns a view object containing the `(key, value)` tuple pairs.                  |
| `.keys()`            | Returns a view object list of all keys in the dictionary.                         |
| `.pop(key)`          | Removes and returns the element with the specified key.                           |
| `.update(iterable)`  | Inserts or updates specified key-value items from another dictionary or iterable. |
| `.values()`          | Returns a view object list of all values in the dictionary.                       |

## Quiz 3

Write a function `is_subset(s1, s2)` that takes in two sets of integers as parameters, and returns `True` if `s1` is a subset of `s2`, or `False` otherwise.

- For example, set {1, 3, 5} is a subset of another set {1, 5, 3, 9}.

- As another example, set {1, 3, 5} is NOT a subset of another set {1, 5, 6, 9} because 3 doesn’t exist in second set.

>[!example]- Answer
> ```run-python
> def is_subset(s1, s2):
> 	if len(s1) > len(s2):
> 		difference = s2 - s1
> 		return len(difference) == 0
> 		
> 	elif len(s1) < len(s2):
> 		difference = s1 - s2
> 		return len(difference) == 0
> 	
> 	else:
> 		return s1 == s2
> 		
> s1 = {1,2,3}
> s2 = {1,2,3}
> 
> print(is_subset(s1,s2))
> ```

## Quiz 4

Write a function `check_duplicate(a)` that takes in a tuple of integers as parameter, and returns `True` if the tuple contains duplicate integers, or `False` otherwise.

- For example, tuple (5, 1, 2, 3) doesn’t contain duplicate value while tuple (5, 2, 1, 2, 3) contains duplicate value.

>[!example]- Answer (Using Sets)
> ```run-python
> def check_duplicate(a):
> 	s1 = {i for i in a}
> 	return len(s1) != len(a)
> 
> t1 = (5,1,2,3)
> t2 = (5,2,1,2,3)
> 
> print(check_duplicate(t2))
> ```

>[!example]- Answer (Using Dictionary)
> ```run-python
> def check_duplicate(a):
> 	d1 = {}
> 	for i in a:
> 		d1[i] = 1
> 	
> 	return len(d1) != len(a)
> 
> t1 = (5,1,2,3)
> t2 = (5,1,2,3,2)
