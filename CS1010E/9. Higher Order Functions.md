# Higher Order Abstraction
In Python, higher-order abstraction is primarily achieved through **Higher-Order Functions (HOFs)**. These are functions that treat other functions as first-class citizens—meaning they can take other functions as arguments, return them as results, or store them in variables. This approach allows you to abstract away repetitive control flow and write highly modular, reusable, and readable code.

## Functions as Arguments

Instead of writing multiple loops for different calculations, one function can be defined to handle the iteration and delegates the logic.

```run-python
def apply_operation(func, numbers):
    """Abstracts the iteration, allowing any function to be applied to a list."""
    return [func(n) for n in numbers]

def square(x):
    return x * x

def cube(x):
    return x * x * x

numbers = [1, 2, 3, 4]
print(apply_operation(square, numbers))  # [1, 4, 9, 16]
print(apply_operation(cube, numbers))    # [1, 8, 27, 64]
```

## Local Variables and Functions

Variables created inside a function are local to it. Python also allows you to define **inner (nested) functions**, which act as local functions and cannot be called from the outside.

```run-python
def outer_function():
    # Local variable
    message = "Hello from the inside!" 
    
    # Local (nested) function
    def local_function():
        print(message)
        
    local_function() # This works fine

outer_function()

# Trying to access them outside causes a NameError
print(message) 
local_function() 
```

## Example: Finding $e^n$

Code:
```run-python
def sum(f, n):
    res = 0
    for i in range(n+1):
        res = res + f(i)
    return res

def find_e(x,n):
    def f(i):
        return x**i/fact(i)
    return sum(f,n)

def fact(x):
	if x <= 1:
		return 1
	elif x > 1:
		return x*fact(x-1)

print(find_e(1,100))
```

### Breakdown of Code

This Python code calculates an approximation of the mathematical constant **$e^x$** (specifically $e^1$, which is just $e \approx 2.71828$) using its **Taylor series expansion**.

Mathematically, the exponential function can be calculated as an infinite sum:

$$e^x = \sum_{i=0}^{\infty} \frac{x^i}{i!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots$$

#### 1. The Factorial Function (`fact`)

Python

```
def fact(x):
    if x <= 1:
        return 1
    elif x > 1:
        return x*fact(x-1)
```

- **What it does:** Calculates the factorial of a number ($x!$) using **recursion**.
    
- **How it works:** If $x$ is 0 or 1, it returns 1 (the base case). Otherwise, it multiplies $x$ by the factorial of $x-1$. For example, `fact(3)` computes $3 \times 2 \times 1 = 6$.
    

#### 2. The Summation Function (`sum`)

Python

```
def sum(f, n):
    res = 0
    for i in range(n+1):
        res = res + f(i)
    return res
```

- **What it does:** This is a **higher-order function** because it takes another function (`f`) as an argument. It computes the mathematical sum $\sum_{i=0}^{n} f(i)$.
    
- **How it works:** It loops from `i = 0` up to `n` (thanks to `range(n+1)`). In each iteration, it runs the function `f(i)` and accumulates the result into `res`.
    

#### 3. The Exponential Approximator (`find_e`)

Python

```
def find_e(x,n):
    def f(i):
        return x**i/fact(i)
    return sum(f,n)
```

- **What it does:** It sets up the specific formula for the Taylor series term: $\frac{x^i}{i!}$.
    
- **How it works:** * Inside `find_e`, a local helper function `f(i)` is defined to calculate a single term of the series: `xi / fact(i)` (where means "to the power of").
    
    - It then passes this specific formula `f` and the limit `n` to the `sum` function we looked at above.
        

#### 4. The Execution (`print(find_e(1,100))`)

Python

```
print(find_e(1,100))
```

- This tells the program to estimate $e^1$ ($x=1$) by adding up the first 101 terms ($n=100$, from $i=0$ to $100$) of the series.
    
- **The output:** Because $n=100$ is a remarkably high number of terms for this fast-converging series, it will print a highly accurate approximation of Euler's number:
    
    **`2.718281828459045`**

# Python Closure

A **Python closure** is an inner function that retains access to variables from its outer (enclosing) function's scope even after the outer function has finished executing. It allows you to bind data to a function without passing those variables as explicit parameters.

A closure is automatically formed in Python when you meet three criteria:

1. You have a **nested function** (a function inside another function).
2. The inner function **references a variable** from the outer function's scope.
3. The outer function **returns the inner function** object.

```run-python
def make_multiplier(factor):
    # Enclosing scope variable
    def multiply(number):
        # Accesses 'factor' from the outer scope
        return number * factor
    
    return multiply  # Returns the function object without calling it

# Create specific variations
double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))  # Output: 10
print(triple(5))  # Output: 15
```

Even though `make_multiplier(2)` has completed its execution, the `double` function still securely remembers that `factor` was set to `2`.

# Anonymous Function

In Python, an anonymous function is -a function defined without a name using the **`lambda` keyword**. These are often called **lambda functions** and are typically used for short, single-expression operations where a standard `def` block would be unnecessary.

**Syntax

```python
lambda arguments: expression
```

- **`lambda`**: The keyword that initiates the function.
- **`arguments`**: A comma-separated list of inputs (zero or more).
- **`expression`**: A single line of code executed and automatically returned. No `return` statement is allowed.

## `def` vs `lambda`

| Feature       | Regular Function (`def`)                | Anonymous Function (`lambda`)           |
| ------------- | --------------------------------------- | --------------------------------------- |
| **Keyword**   | Uses `def`                              | Uses `lambda`                           |
| **Name**      | Must have an explicit name              | Unnamed (anonymous)                     |
| **Body Size** | Can contain multiple lines and blocks   | Strictly limited to one expression      |
| **Return**    | Requires an explicit `return` statement | Implicitly returns the evaluated result |
## Basic Usage

```run-python
# Squaring a number immediately
result = (lambda x: x ** 2)(5)
print(result)  # Output: 25

# Storing it in a variable (essentially naming it)
add = lambda a, b: a + b
print(add(3, 7))  # Output: 10
```

Equivalent to:

```run-python
def result(x):
	return x**2

print(result(5))

def add(a, b):
	return a + b
	
print(add(3, 7))
```
