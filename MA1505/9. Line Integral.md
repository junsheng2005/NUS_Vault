# [[Vector Field]]

## 2 Dimensional

Let $R$ be a region in $xy$ plane. A vector field on $R$ is a vector function $\mathbf{F}$ that assigns each point $(x,y)$ in $R$ a two dimensional vector $\mathbf{F}(x,y)$. Where $\mathbf{F}(x,y)$ is represented as $$\mathbf{F}(x,y)=P(x,y)\mathbf{i}+Q(x,y)\mathbf{j}=P\mathbf{i}+Q\mathbf{j}=\left\langle P,Q\right\rangle$$

## 3 Dimensional

Let $D$ be a solid region in $xyz$ space. A vector field on $D$ is a vector function $\mathbf{F}$ that assigns each point $(x,y,z)$ in $D$ a three dimensional vector $\mathbf{F}(x,y)$. Where $\mathbf{F}(x,y,z)$ is represented as $$\mathbf{F}(x,y,z)=P(x,y,z)\mathbf{i}+Q(x,y,z)\mathbf{j}+R(x,y,z)\mathbf{k}=P\mathbf{i}+Q\mathbf{j}+R\mathbf{k}=\left\langle P,Q,R\right\rangle$$
# [[Gradient Field]]

$$
	\nabla f(x,y,z)=f_{x}(x,y,z)\mathbf{i}+f_{y}(x,y,z)\mathbf{j}+f_{z}(x,y,z)\mathbf{k}
$$
Where
$\nabla f(x,y,z)$ is the gradient field of $f$

>[!note] 
>The vector $\nabla f$ is normal to the tangent vector of a curve/surface
# Conservative Field

A vector field $\mathbf{F}$ is called a conservative vector field if there is a function $f$ such that
$$
	\mathbf{F}=\nabla f
$$
$f$ is called a potential function for $\mathbf{F}$

## Criteria of Conservative Fields

1. Let $F=P\mathbf{i}+Q\mathbf{j}$ be a vector field on the $xy$ plane
	If $\frac{ \partial P }{ \partial y }=\frac{ \partial Q }{ \partial x }$, then $\mathbf{F}$ is conservative

2. Let $F=P\mathbf{i}+Q\mathbf{j}+R\mathbf{k}$ be a vector field on the $xyz$ space
	If$\frac{ \partial P }{ \partial y }=\frac{ \partial Q }{ \partial x },\frac{ \partial P }{ \partial z }=\frac{ \partial R }{ \partial x },\frac{ \partial Q }{ \partial z }=\frac{ \partial R }{ \partial y }$, then $\mathbf{F}$ is conservative

## Consequences of Conservative Fields

1. If $\mathbf{F}$ is a conservative field, then $\int_{C}\mathbf{F}\cdot d\mathbf{r}$ is independent of path, i.e. $\int_{C_{1}}\mathbf{F}\cdot d\mathbf{r}=\int_{C_{2}}\mathbf{F}\cdot d\mathbf{r}$ for any 2 paths with the same initial and terminal points

2. If $\mathbf{F}$ is a conservative field, then $\oint_{\ell}\mathbf{F}\cdot d\mathbf{r}=0$ for any closed curve $\ell$  
# [[Line Integrals]]

## Scalar Functions

$$
	\int_{C}f(x,y,z)ds=\int_{a}^b f(\mathbf{r}(t))\ ||\mathbf{r}'(t)||\ dt
	$$
$$
	\int_{C}f(x,y,z)ds=\int_{a}^b f(x(t),y(t),z(t))\ \sqrt{ \left( \frac{dx}{dt} \right)^2+\left( \frac{dy}{dt} \right)^2+\left( \frac{dz}{dt} \right)^2 }\ dt
	
$$
Where
$\mathbf{r}(t)=x(t)\mathbf{i}+y(t)\mathbf{j}+z(t)\mathbf{k}$ is the vector equation of the parametric equation of $C$ in terms of $t$. i.e $C:x(t),y(t),\text{where}\  a<t<b$ 
$a$ and $b$ are the limits of $t$

Note: If $\mathbf{r}(t)=x(t)\mathbf{i}+y(t)\mathbf{j}+z(t)\mathbf{k}$, then $f(\mathbf{r}(t))=f(x(t),y(t),z(t))$
## Vector Functions

$$
	\int_{C}\mathbf{F}\cdot d\mathbf{r}=\int _{a}^b\mathbf{F}(\mathbf{r}(t))\cdot \mathbf{r}'(t)dt
$$
## Piecewise Smooth Curve

The union of a finite number of smooth curves is denoted by,
$$
	C=C_{1}+C_{2}+\dots C_{n}
$$
>[!info]- Image
![[9. Line Integral-1780887644435.webp|299]]

Then the line integral of $f$ along $C$ is defined to be,
$$
	\int_{C}fds=\int_{C_{1}}fds+\int_{C_{2}}fds+\dots+\int_{C_{n}}fds
$$
## Line Integrals in Component Form

Suppose $\mathbf{F}(x,y,z)=P\mathbf{i}+Q\mathbf{j}+R\mathbf{k}$ and $C\ :\ \mathbf{r}(t)=x(t)\mathbf{i}+y(t)\mathbf{j}+z(t)\mathbf{k}$,
The line integral may be written as,
$$
	\int_{C}\mathbf{F}\cdot d\mathbf{r}=\int_{C}Pdx+Qdy+Rdz

$$
Using [[Chain Rule]],

$$
\int_{C}Pdx+Qdy+Rdz=\int_{C}P(\mathbf{r}(t)) \frac{dx}{dt}dt+Q(\mathbf{r}(t)) \frac{dy}{dt}dt+R(\mathbf{r}(t)) \frac{dz}{dt }dt
$$
## The Fundamental Theorem for Line Integral
$$
	\int_{C}\nabla f\cdot d\mathbf{r}=f(\mathbf{r}(b))-f(\mathbf{r}(a))
$$
**Where**
The curve $C$ is a smooth curve with the vector function $\mathbf{r}(t),t \in[a,b]$

# [[Work Done]]

## Linear Work Done

$$
	W=\mathbf{F}\cdot \mathbf{s}
$$
$$
	W=Fs\cos\theta
$$
Where
$W$ is work done by force $\mathbf{F}$ on the object
$\mathbf{F}$ is the constant force vector acting on the object
$\mathbf{s}$ is the displacement vector of the object
$\theta$ is the angle between $\mathbf{F}\  \text{and} \ \mathbf{s}$ 

# Work Done by a Variable Force, Moving along a Curve

$$
	W=\int_{C}\mathbf{F}(x,y,z)\cdot d\mathbf{r}

$$
Where
$W$ is work done by force $\mathbf{F}$ on the object
$\mathbf{F}$ is the variable force acting on the object
$\mathbf{r}$ is the vector equation of the curve $C$
$\int_{C}$ denotes a line integral 

# [[Green's Theorem]]
 $$
	\oint_{\partial D}Pdx+Qdy=\iint_{D}\left( \frac{ \partial Q }{ \partial x } -\frac{ \partial P }{ \partial y }  \right)dA
 $$

**Where**
$D$ is the bounded region in the $xy$ plane
$\partial D$ is the boundary of $D$

>[!note]
> The positive orientation of $\partial D$ is in the anti-clockwise direction if seen from the top of $xy$ plane
