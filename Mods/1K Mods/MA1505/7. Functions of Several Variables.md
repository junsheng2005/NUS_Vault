# Partial Derivatives

Let $f(x,y)$ be a function of two variables. The partial derivative of $f$ with respect to $x$ $(\frac{ \partial f }{ \partial x }\ \text{or}\ f_{x})$ can be obtained by fixing the variable $y$ as a constant (Treat $y$ as a constant).

>[!example]- Example
> Let $f(x,y) = (x^3 + y) \cos(y^2)$.
> 
> Find $f_x(2,0)$, and $f_y(2,0)$.
> 
> **Solution:** Treat $y$ as a constant and compute
> 
> $$\begin{aligned} f_x &= \frac{d}{dx}f(x,y) = \frac{d}{dx}(x^3 + y)\cos(y^2) \\ &= 3x^2\cos(y^2) \end{aligned}$$
> 
> Then $f_x(2,0) = 3(2)^2\cos(0^2) = 12$.
> 
> Treat $x$ as a constant and compute
> 
> $$\begin{aligned} f_y &= \frac{d}{dy}f(x,y) = \frac{d}{dy}(x^3 + y)\cos(y^2) \\ &= \cos(y^2) - (x^3 + y)\sin(y^2)2y. \end{aligned}$$
> 
> Then $f_y(2,0) = \cos(0^2) - (2^3 + 0)\sin(0^2)2(0) = 1$.

## Second Order Partial Derivatives

The second order partial derivatives of $f$ are:
$$\begin{aligned} f_{xx} &= (f_x)_x = \frac{\partial^2 f}{\partial x^2} \quad &f_{xy} = (f_x)_y = \frac{\partial^2 f}{\partial y \partial x} \\ f_{yx} &= (f_y)_x = \frac{\partial^2 f}{\partial x \partial y} \quad &f_{yy} = (f_y)_y = \frac{\partial^2 f}{\partial y^2}. \end{aligned}$$
If $z=f(x,y)$,
$$f_{xx} = \frac{\partial^2 z}{\partial x^2} \quad f_{xy} = \frac{\partial^2 z}{\partial y \partial x} \quad f_{yx} = \frac{\partial^2 z}{\partial x \partial y} \quad f_{yy} = \frac{\partial^2 z}{\partial y^2}$$
>[!example]- Example
> Find the second partial derivatives of
> 
> $$f(x,y) = 4x^3 + x^2y^3 - 6y^2.$$
> 
> **Solution:** We have $f_x = 12x^2 + 2xy^3$, so
> 
> $$f_{xx} = 24x + 2y^3, \quad f_{xy} = 6xy^2.$$
> 
> We have $f_y = 3x^2y^2 - 12y$, so
> 
> $$f_{yx} = 6xy^2, \quad f_{yy} = 6x^2y - 12.$$

## Mixed Derivatives

For most functions in practice,
$$
	f_{xy}(a,b)=f_{yx}(a,b)
$$
# Chain Rule

## Chain Rule for One Independent Variable on $f(x,y)$

Suppose $z = f(x, y)$ is a function of two variables $x$ and $y$, and $x = x(t)$, $y = y(t)$ are both functions of $t$. Then $z$ is a function of $t$: $z(t) = f(x(t), y(t))$

and
$$\frac{dz}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} + \frac{\partial f}{\partial y} \frac{dy}{dt}.$$
## Chain Rule for Two Independent Variables on $f(x,y)$

Suppose $z = f(x, y)$ is a function of two variables $x$ and $y$, and $x = x(s, t)$, $y = y(s, t)$ are both functions of two variables $s$ and $t$. Then $z$ is a function of $s$ and $t$: $z(s, t) = f(x(s, t), y(s, t))$ and
$$\frac{\partial z}{\partial s} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial s} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial s} \quad \text{and} \quad \frac{\partial z}{\partial t} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t}$$
## Chain Rule for One Independent Variable on $f(x,y,z)$

Suppose $w = f(x, y, z)$ is a function of three variables $x, y$ and $z$, and $x = x(t)$, $y = y(t)$, $z = z(t)$ are functions of $t$. Then $w$ is a function of $t$: $w(t) = f(x(t), y(t), z(t))$ and 
$$\frac{dw}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} + \frac{\partial f}{\partial y} \frac{dy}{dt} + \frac{\partial f}{\partial z} \frac{dz}{dt}.$$
## Chain Rule for Two Independent Variables on $f(x,y,z)$

Suppose $w = f(x, y, z)$ is a function of three variables $x, y$ and $z$, and $x = x(s, t)$, $y = y(s, t)$, $z = z(s, t)$ are functions of two variables $s$ and $t$.

Then $w$ is a function of $s$ and $t$: $w(s, t) = f(x(s, t), y(s, t), z(s, t))$ and 
$$\begin{aligned} \frac{\partial w}{\partial s} &= \frac{\partial f}{\partial x} \frac{\partial x}{\partial s} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial s} + \frac{\partial f}{\partial z} \frac{\partial z}{\partial s} \\ \frac{\partial w}{\partial t} &= \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t} + \frac{\partial f}{\partial z} \frac{\partial z}{\partial t} \end{aligned}$$

$$
	D_{\mathbf{u}}f(x,y)=fx(x,y)u_{1}+f_{y}(x,y)u_{2}

The gradient of $f(x,y)$ is the vector function
$$
	\nabla f=f_{x}\mathbf{i}+f_{y}\mathbf{j}
$$
For a given vector $u=u_{1}\mathbf{i}+u_{2}\mathbf{j}$,
$$
		D_{\mathbf{u}}f(x,y)=\nabla f\cdot \mathbf{u}=fx(x,y)u_{1}+f_{y}(x,y)u_{2}
$$
### Properties of Gradient Vector

1. The function $f$ increases most rapidly in the direction of $\nabla f$
2. The function $f$ decreases most rapidly in the direction of $\nabla f$
3. The function $\nabla f$ is normal to the surface of $f(x,y)$

# Critical Points

A function $f$ may have a local maximum, minimum or a saddle point at $(a,b)$ if
1. $f_{x}(a,b)=0\ \text{and}\ f_{y}(x,y)=0;\text{or}$
2. $f_{x}(a,b)$ or $f_{y}(x,y)$ does not exist.

## Saddle Point

A point $(a,b)$ is a saddle point of $f$ is there are some directions along which $f$ has a local maximum at $(a,b)$ and some direction along which $f$ has a local minimum at $(a,b)$.

## Second Derivative Test

$$
	D=f_{xx}(a,b)f_{yy}(a,b)-f_{xy}(a,b)\ ^2
$$
1. If $D>0$ and $f_{xx}(a,b)>0$, then $f$ has a local minimum at $(a,b)$.
2. If $D>0$ and $f_{xx}(a,b)<0$, then $f$ has a local maximum at $(a,b)$.
3. If $D<0$, then $f$ has a saddle point at $(a,b)$.
4. If $D=0$, then no conclusion can be drawn.

# Lagrange Multiplier

Lagrange Multiplier is used for optimisation problems where a function is subjected to certain constraints

>[!example]- Example
> Find relative extrema of
> 
> $$z = f(x,y) = 12x - 16y + 50$$
> 
> subject to the constraint $x^2 + y^2 = 25.$
> 
> **_Solution._** The constraint is written as
> 
> $$g(x,y) = x^2 + y^2 - 25.$$
> 
> The following function is constructed:
> 
> $$F(x, y, \lambda) = f(x, y) - \lambda g(x, y)$$
> 
> $$= 12x - 16y + 50 - \lambda(x^2 + y^2 - 25).$$
> 
> Then set $F_x = 0, F_y = 0, F_\lambda = 0$ to get respectively
> 
> $$12 - 2\lambda x = 0$$
> 
> $$-16 - 2\lambda y = 0$$
> 
> $$-x^2 - y^2 + 25 = 0$$
> 
> Writing the first two equations as $x = \frac{6}{\lambda}, y = \frac{-8}{\lambda}$
> 
> and substituting into the third equation, we obtain
> 
> $$-\frac{36}{\lambda^2} - \frac{64}{\lambda^2} + 25 = 0$$
> 
> $$\lambda^2 = \frac{100}{25} = 4$$
> 
> $$\lambda = \pm 2$$
> 
> If $\lambda = 2$, then $x = \frac{6}{2} = 3, y = \frac{-8}{2} = -4$ and
> 
> $$z = f(3,-4) = 12(3) - 16(-4) + 50 = 150.$$
> 
> If $\lambda = -2$, then $x = \frac{6}{-2} = -3, y = \frac{-8}{-2} = 4$ and
> 
> $$z = f(-3,4) = 12(-3) - 16(4) + 50 = -50.$$
> 
> Thus, subject to the constraint $x^2 + y^2 = 25$, the function $z = f(x,y) = 12x - 16y + 50$ attains:
> 
> (1) a local maximum of $z = f(3,-4) = 150$; and
> 
> (2) a local minimum of $z = f(-3,4) = -50.$
