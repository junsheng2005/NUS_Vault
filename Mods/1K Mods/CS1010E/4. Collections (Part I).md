# Tuple

A **tuple** is a built-in collection data type used to store multiple items in a single variable. The core definition of a tuple is that it is **ordered**, **immutable (unchangeable)**, and **allows duplicate values**. 

## Basic Operations and Syntax

Tuples are defined using parentheses `()` with items separated by commas.

```python
# Empty tuple
empty_tuple = ()

# Tuple with multiple data types
user_profile = ("Alice", 28, "Engineer")

# CRITICAL: A single-item tuple REQUIRES a trailing comma
single_item = ("Apple",) 
not_a_tuple = ("Apple")  # This is interpreted as a standard string!
```

## Accessing Elements

```run-python
fruits = ("apple", "banana", "cherry", "date")
#Index:      0         1         2        3
#Index:     -4        -3        -2       -1

print(fruits[0])      # Output: "apple"
print(fruits[-1])     # Output: "date" (negative indexing)
print(fruits[1:3])    # Output: ('banana', 'cherry') (slicing)
```

## Tuple Operations

### Concatenation
```run-python
tuple1 = (1, 2, 3)
tuple2 = (4, 5, 6)

combined = tuple1 + tuple2
print(combined)  # Output: (1, 2, 3, 4, 5, 6)

```

### Replication
```run-python
fruits = ("apple", "banana")

repeated = fruits * 3
print(repeated)  # Output: ('apple', 'banana', 'apple', 'banana', 'apple', 'banana')

```

### Slicing
```run-python
letters = ('a', 'b', 'c', 'd', 'e', 'f', 'g')

print(letters[1:4])    # Output: ('b', 'c', 'd')
print(letters[::2])     # Output: ('a', 'c', 'e', 'g') (steps of 2)
print(letters[::-1])    # Output: ('g', 'f', 'e', 'd', 'c', 'b', 'a') (reverses tuple)

```

### Membership Testing (`in`/`not in`)
```run-python
colors = ("red", "green", "blue")

print("green" in colors)      # Output: True
print("yellow" not in colors)  # Output: True

```

### Len(), max(), min(), sum(), sorted()
```run-python
numbers = (10, 5, 8, 20, 3)

# len(): Get total number of items
print(len(numbers))  # Output: 5

# max() and min(): Get highest and lowest values
print(max(numbers))  # Output: 20
print(min(numbers))  # Output: 3

# sum(): Add all numerical elements together
print(sum(numbers))  # Output: 46

# sorted(): Returns a SORTED LIST version of the tuple
print(sorted(numbers))  # Output: [3, 5, 8, 10, 20]

```

### Iterating Through a Tuple
```run-python
brands = ("Apple", "Google", "Microsoft")

for brand in brands:
    print(brand)

```

**Example:
Given a sequence of coin denominations: 1¢, 5¢, 10¢, 20¢, 50¢, and $1, write a function to find the least number of coins needed for a given amount.

```run-python
def compute_coins(amt):
	amt = float(amt)
	denoms = (100, 50, 20, 10, 5, 1)
	coins = 0
	for i in denoms:
		coins += amt//i
		amt = amt % i
	return coins
		
x = compute_coins(input('Enter amount in cents: '))
print(x)
```

# List

A **Python list** is a built-in, mutable, and ordered collection of elements enclosed in square brackets `[]`. It allows you to store items of **different data types** in a single variable, and supports duplicate values

## Basic Operations and Syntax

Lists are defined using square brackets `[]` with items separated by commas.

```run-python
# Creating a list
fruits = ["apple", "banana", "cherry"]

# Accessing elements (Zero-indexed)
print(fruits[0])        # Output: apple

# Negative indexing (Starts from the end)
print(fruits[-1])       # Output: cherry

# Slicing a list [start:stop]
print(fruits[0:2])      # Output: ['apple', 'banana']
```

## Accessing Elements

```run-python
fruits = ["apple", "banana", "cherry", "date"]
#Index:      0         1         2        3
#Index:     -4        -3        -2       -1

print(fruits[0])      # Output: "apple"
print(fruits[-1])     # Output: "date" (negative indexing)
print(fruits[1:3])    # Output: ('banana', 'cherry') (slicing)
```

## List Operations

### Adding Elements

- `append(x)`: Adds item `x` to the end.
- `extend(iterable)`: Appends all items from an iterable to the end.
- `insert(i, x)`: Inserts item `x` at a specific index `i`

```run-python
nums = [1, 2]

nums.append(4)          # [1, 2, 4]
print(nums)

nums.extend([5, 6])     # [1, 2, 4, 5, 6]
print(nums)

nums.insert(2, 3)       # [1, 2, 3, 4, 5, 6]
print(nums)
```

### Removing Element

- `remove(x)`: Removes the first occurrence of value `x`. Raises `ValueError` if missing.
- `pop([i])`: Removes and returns the item at index `i`. Defaults to the last item.
- `clear()`: Removes all items, leaving an empty list.
- `del`: Keyword to delete specific indices or entire slices.

```run-python
items = ['a', 'b', 'c', 'b']

items.remove('b')       # ['a', 'c', 'b']
print(items)

last = items.pop()      # 'b' is returned;items becomes ['a','c']
print(items)

del items[0]            # ['c']
print(items)

items.clear()           # []
print(items)
```

### Searching & Information

- `index(x)`: Returns the zero-based index of the first occurrence of `x`.
- `count(x)`: Returns the total number of times `x` appears.
- `in` / `not in`: Checks for element membership.
- `len(list)`: Built-in function returning the total item count.

```run-python
chars = ['x', 'y', 'z', 'x']

idx = chars.index('y')  # 1
print(idx)

cnt = chars.count('x')  # 2
print(cnt)

is_present = 'z' in chars  # True
print(is_present)

length = len(chars)
print(f'The total item in the list is: {length}')
```

### Utility Operations

- `sort()`: Sorts the list items in place.
- `reverse()`: Reverses the elements of the list in place.
- `copy()`: Returns a shallow copy of the list.

```run-python
vals = [3, 1, 2]

vals.sort()             # [1, 2, 3]
print(vals)

vals.reverse()          # [3, 2, 1]
print(vals)

dup = vals.copy()       # [3, 2, 1]
print(dup)
```

### Slicing and Operators

- `list[start:stop:step]`: Extracts a sublist. `stop` index is excluded.
- `+` Operator: Concatenates two lists together.
- `*` Operator: Repeats a list a specific number of times.

```run-python
letters = ['a', 'b', 'c', 'd']

sub = letters[1:3]      # ['b', 'c']
print(sub)

combined = [1, 2] + [3] # [1, 2, 3]
print(combined)

repeated = ['a'] * 3    # ['a', 'a', 'a']
print(repeated)

```

## List Comprehensions

**Python list comprehensions** provide a concise, one-line syntax to create new lists from existing iterables like lists, tuples, or ranges. They replace verbose `for` loops, making your code cleaner and often faster to execute.

### Basic Syntax

```python
new_list = [expression for item in iterable]
```

### Traditional Loop vs List Comprehensions

**Traditional Loop:
```run-python
numbers = [1, 2, 3, 4]
squares = []
for num in numbers:
    squares.append(num ** 2)
# Output: [1, 4, 9, 16]

print(squares)
```

**List Comprehension:
```run-python
numbers = [1, 2, 3, 4]
squares = [num ** 2 for num in numbers]
# Output: [1, 4, 9, 16]

print(squares)
```

### Adding Conditions

**Filtering with `if`

```run-python
# Keep only even numbers
numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
# Output: [2, 4, 6]

print(evens)
```

**Transforming with `if-else` 

```run-python
# Label numbers as 'Even' or 'Odd'
numbers = [1, 2, 3, 4]
labels = ["Even" if n % 2 == 0 else "Odd" for n in numbers]
# Output: ['Odd', 'Even', 'Odd', 'Even']

print(labels)
```

**Nested Loops

```run-python
pairs = [(x, y) for x in range(2) for y in range(2)]
# Output: [(0, 0), (0, 1), (1, 0), (1, 1)]

print(pairs)
```

**Flattening a 2D Matrix

```run-python
matrix = [[1, 2], [3, 4]]
flat = [num for row in matrix for num in row]
# Output: [1, 2, 3, 4]

print(flat)
```
