# Selection Statements

## If statements

If the condition is `True`, executes the respective statements.

![[Control Structures-1781613067896.webp|438]]

**Example:**

```run-python
test_score = 30
if test_score < 40:
	print("Opps, you fail\nTry harder next time!")
```
- Note: `\n` inserts an Enter

## If-else Statement

If the condition is `True` execute statement_1; otherwise execute statement_2

![[Control Structures-1781613355559.webp|432]]

**Example:**

```run-python
test_score = 50
if test_score < 40:
	print("Opps, you fail\nTry harder next time!")
else:
	print("You Pass!")
```

## If-elif Statement

In Python, the **`if-elif-else` statement** is used to control the execution flow of a program by evaluating multiple conditions in sequence. The keyword **`elif`** stands for **"else if"** and runs only if all previous conditions evaluate to `False`

**Example:**

```run-python
score = 85

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")  # This block executes because 85 >= 80 is True
elif score >= 70:
    print("Grade: C")  # Skipped, even though 85 >= 70 is also True
else:
    print("Grade: F")  # Catch-all fallback block

```

## Nested if-else Statements
A **nested `if...else` statement** in Python means placing an `if`, `elif`, or `else` block inside the body of another `if` or `else` block. This structure creates hierarchical decision trees where secondary conditions are evaluated **only after** a primary condition passes or fails.

**Example 1:**
```run-python
username = "admin"
password = "secure_password"

# Step 1: Check if the username exists
if username == "admin":
    # Step 2: Check the password only if the username is correct
    if password == "secure_password":
        print("Welcome back! Access granted.")
    else:
        print("Incorrect password. Try again.")
else:
    print("Username not found.")

```

**Example 2:**
```run-python
age = 65
has_membership = False

if age < 18:
    if has_membership:
        print("Child Member Ticket: $5")
    else:
        print("Standard Child Ticket: $10")
else:
    # This nested block only evaluates if age is 18 or older
    if has_membership:
        print("Adult Member Ticket: $12")
    else:
        print("Standard Adult Ticket: $20")

```

# Repetition Statements

**Python repetition statements**, also known as loops, let you execute a block of code multiple times automatically. Python provides two primary types of repetition statements: **`for` loops** (for iterating over a predetermined sequence) and **`while` loops** (for repeating code as long as a condition is true)

![[Control Structures-1781620202754.webp|278]]

## While Loop

A `while` loop iteratively evaluate condition and then execute the loop body, until condition is `False`.

**Example:**
```run-python
count = 5
while count > 0:
	print(count)
	count -= 1 #equivalent to count = count - 1
```

**Example:**
Given a positive integer $n$, print all the positive odd integers up to $n$.
```run-python
n = int(input('Enter n: '))
i = 1
while i <= n:
	if i%2 != 0:
		print(i)
	i += 1	
```

## For Loop
The `for` loop executes a block of code a set number of times. It directly steps through elements in an iterable collection like lists, strings, dictionaries, or ranges.

### Range() 
The Python **`range()`** function generates an **immutable sequence of integers** on the fly, which is most commonly used to control the number of iterations in a `for` loop.

`range(start, stop, step)`

| Arguments Provided | Syntax                     | Behavior                                                          | Example           | Resulting Sequence |
| ------------------ | -------------------------- | ----------------------------------------------------------------- | ----------------- | ------------------ |
| **1 Argument**     | `range(stop)`              | Starts at `0`, increments by `1`, stops **before** `stop`.        | `range(5)`        | `0, 1, 2, 3, 4`    |
| **2 Arguments**    | `range(start, stop)`       | Starts at `start`, increments by `1`, stops **before** `stop`.    | `range(2, 6)`     | `2, 3, 4, 5`       |
| **3 Arguments**    | `range(start, stop, step)` | Starts at `start`, increments by `step`, stops **before** `stop`. | `range(1, 10, 2)` | `1, 3, 5, 7, 9`    |
**Examples:**
```run-python
#Prints 0 to 4
for i in range(5):
	print(i)
```

```run-python
#Prints every number from 3 to 9
for i in range(3,10):
	print(i)
```

```run-python
#Prints every 4th number from 3 to 9 starting from 3
for i in range(3,10,4):
	print(i)
```

```run-python
#Prints in reverse from 5 to 1
for i in range(5,0,-1):
	print(i)
```

Given a positive integer $n$, print all the positive odd integers up to $n$.
```run-python
n = int(input("Enter n: "))
for i in range(1,n+1,2):
	print(i)
```

## Break and Continue
The **`break`** completely terminates the current loop, while **`continue`** skips the rest of the current iteration and jumps directly to the next cycle. Both statements work inside `for` and `while` loops.

**Examples:**
```run-python
# Stops printing as soon as it hits 5
for num in range(1, 10):
    if num == 5:
        break
    print(num)

# Output: 1, 2, 3, 4
```

```run-python
# Skips printing 5, but continues with 6, 7...
for num in range(1, 6):
    if num == 3:
        continue
    print(num)

# Output: 1, 2, 4, 5

```

## Nested Loops

A **nested loop** is a loop placed inside the body of another loop. 

The **inner loop executes completely** for every single iteration of the outer loop. You can nest `for` loops inside `for` loops, `while` loops inside `while` loops, or mix them together.

**Example:**
```run-python
# Outer loop
for i in range(1, 4):
    # Inner loop
    for j in range(1, 3):
        print(f"Outer i={i}, Inner j={j}")

```

```run-python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Process each row, then each item inside that row
for row in matrix:
    for item in row:
        print(item, end=" ")
    print()  # Prints a newline after completing an entire row

```
