# Object Oriented Programming (OOP)

**Object-Oriented Programming (OOP)** is a programming paradigm in Python that organizes code around **classes** and **objects** to mirror real-world entities and behaviours.

## Advantages of OOP

- Provides a clear structure to programs
- Makes code easier to maintain, reuse, and debug
- Helps keep your code DRY (**Don't Repeat Yourself**)
- Allows you to build reusable applications with less code

Note: The DRY principle means you should avoid writing the same code more than once. Move repeated code into functions or classes and reuse it.

## Class vs Object

A class defines what an object should look like, and an object is created based on that class. For example:

|Class|Objects|
|---|---|
|Fruit|Apple, Banana, Mango|
|Car|Volvo, Audi, Toyota|

# Classes and Objects

Python is an object oriented programming language.
Almost everything in Python is an object, with its properties and methods.
A Class is like an object constructor, or a "blueprint" for creating objects.

## `__init__()` Method    

All classes have a built-in method called `__init__()`, which is always executed when the class is being initiated.

The `__init__()` method is used to assign values to object properties, or to perform operations that are necessary when the object is being created.

```run-python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p1 = Person("Emil", 36)

print(p1.name) #returns Emil
print(p1.age) #returns 36
```

- The `__init__()` method is called automatically every time the class is being used to create a new object.

- `self` argument is a reference to the object/instance calling the method

- It allows the **method** (e.g. `.append()` for class `list` and `.upper()` for class `str`)to reference properties specific to the instance.

- The `.name` and `.age` are **attributes** of the object

### Why use `__init__()`

Without the `__init__()` method, you would need to set properties manually for each object:

```run-python
class Person:
    pass

p1 = Person()

p1.name = "Tobias"
p1.age = 25

print(p1.name) #returns Tobias
print(p1.age) #retruns 25
```

Using `__init__()` makes it easier to create objects with initial values:

```run-python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p1 = Person("Linus", 28)

print(p1.name) # returns Linus
print(p1.age)  # returns 28
```

### Default Value in `__init__()`

```run-python
class Person:
    def __init__(self, name, age=18):
        self.name = name
        self.age = age

p1 = Person("Emil")
p2 = Person("Tobias", 25)

print(p1.name, p1.age) #returns Emil 18
print(p2.name, p2.age) #returns Tobias 25
```

- `age` attribute is set to `18` by default 

## The `self` Parameter

The `self` parameter is a reference to the current instance of the class.

It is used to access properties and methods that belong to the class.

```run-python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print("Hello, my name is " + self.name)

p1 = Person("Emil", 25)
p1.greet() #returns "Hello, my name is Emil"
```

### Accessing Properties with `self`

```run-python
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year

    def display_info(self):
        print(f"{self.year} {self.brand} {self.model}")

car1 = Car("Toyota", "Corolla", 2020)
car1.display_info() #returns "2020 Corolla Toyota"
```

### Calling Methods with self

```run-python
class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return "Hello, " + self.name

    def welcome(self):
        message = self.greet()
        print(message + "! Welcome to our website.")

p1 = Person("Tobias")
p1.welcome() #returns "Hello, Tobias! Welcome to our website"
```

## Properties

Properties defined inside `__init__()` belong to each object (instance properties).

Properties defined outside methods belong to the class itself (class properties) and are shared by all objects:

```run-python
class Person:
    species = "Human" # Class property

    def __init__(self, name):
        self.name = name # Instance property

p1 = Person("Emil")
p2 = Person("Tobias")

print(p1.name)
print(p2.name)
print(p1.species)
print(p2.species)
```

### Modifying Properties

#### Class Properties
```run-python
class Person:
    lastname = ""

    def __init__(self, name):
        self.name = name

p1 = Person("Linus")
p2 = Person("Emil")

Person.lastname = "Refsnes"

```

#### Object Properties

```run-python

        self.name = name
        self.age = age

```

### Delete Properties

```run-python

    def __init__(self, name, age):
        self.name = name
        self.age = age
```


# Inheritance

Inheritance allows us to define a class that inherits all the methods and properties from another class.

**Parent class** is the class being inherited from, also called base class.

**Child class** is the class that inherits from another class, also called derived class.

```run-python
class Person:
    def __init__(self, fname, lname):
        self.firstname = fname
        self.lastname = lname

    def printname(self):
        print(self.firstname, self.lastname)

# Use the Person class to create an object, and then execute the printname method:

# Child Class Student inheriting from Person
class Student(Person):
    def __init__(self, fname, lname, year, class_):
        super().__init__(fname, lname)
        self.year = year
        self.class_ = class_
    
    def welcome(self):
        print(f"Welcome {self.firstname} {self.lastname}, from year {self.year} class {self.class_}")
        
# Child Class Teacher inheriting from Person
class Teacher(Person):
    def __init__(self, fname, lname, subject):
        super().__init__(fname, lname)
        self.subject = subject
        
    def printname(self): # Overwrites parent method
        print(f"{self.firstname} {self.lastname} Teaches: {self.subject}")
        
s1 = Student("John", "Doe", 4, "H")
s1.printname() # returns John Doe
s1.welcome()   # returns Welcome John Doe, from year 4 class H

t1 = Teacher("Melvin", "Tan", "Math")
t1.printname() # returns Melvin Tan Teaches: Math
```

## Creating a Parent Class

Any class can be a parent class, so the syntax is the same as creating any other class:

```run-python
class Person:
    def __init__(self, fname, lname):
        self.firstname = fname
        self.lastname = lname

    def printname(self):
        print(self.firstname, self.lastname)
```

## Creating a Child Class

To create a class that inherits the functionality from another class, send the parent class as a parameter when creating the child class:

```run-python
# Child Class Student inheriting from Person
class Student(Person):
    def __init__(self, fname, lname, year, class_):
        super().__init__(fname, lname)
        self.year = year
        self.class_ = class_
    
    def welcome(self):
        print(f"Welcome {self.firstname} {self.lastname}, from year {self.year} class {self.class_}")
        
# Child Class Teacher inheriting from Person
class Teacher(Person):
    def __init__(self, fname, lname, subject):
        super().__init__(fname, lname)
        self.subject = subject
        
    def printname(self): # Overwrites parent method
        print(f"{self.firstname} {self.lastname} Teaches: {self.subject}")
```

### super() Function

 `super()` function will make the child class inherit all the methods and properties from its parent:

```python
class Student(Person):
    def __init__(self, fname, lname, year, class_):
        super().__init__(fname, lname)
```

## Method Overriding

When refining a method with the same name as a method in the parent class, the redefined method will be called instead of the parent's one.
