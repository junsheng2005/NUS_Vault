# Scaling

## Scaling by Iteration

Iterate through a given sequence and scale every element and append to result

```python
def scale_I(seq,n):
	res = []
	for elem in seq:
		res.append(elem*n)
	return res
```

## Scaling by Recursion

```python
def scale_R(seq,n):
	if not seq:
		return []
	else:
		return [seq[0]*n] + scale_R(seq[1:],n)
```

# Map() Function

The `map()` function executes a specified function for each item in an iterable. The item is sent to the function as a parameter.

**Syntax
```python
map(function, iterables)
```

![[10. Map, Filter, Deepmap-1782115660311.webp]]

## Basic Usage
```run-python
# Convert a list of strings to integers
string_numbers = ["1", "2", "3", "4"]
integers = list(map(int, string_numbers))

print(integers)  # Output: [1, 2, 3, 4]
```

## Using map() with Lambda Functions

```python
# Square every number in a list
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))

print(squared)  # Output: [1, 4, 9, 16]
```

## Using map() with multiple Iterables

```run-python
# Add elements of two lists together
list_a = [1, 2, 3]
list_b = [10, 20, 30, 40]  # "40" is ignored because list_a is shorter

sums = list(map(lambda x, y: x + y, list_a, list_b))

print(sums)  # Output: [11, 22, 33]
```

# Filter() Function

The `filter()` function returns an iterator where the items are filtered through a function to test if the item is accepted or not.

**Syntax
```python
filter(function, iterable)
```

## Basic Usage

```run-python
# Function that checks if a number is even
def is_even(num):
    return num % 2 == 0

numbers = [1, 2, 3, 4, 5, 6]

# Apply filter
filtered_iterator = filter(is_even, numbers)

# Convert the iterator to a readable list
even_numbers = list(filtered_iterator)
print(even_numbers)  # Output: [2, 4, 6]
```

## Using Lambda Function

```run-python
numbers = [10, 15, 20, 25, 30]

# Filter numbers greater than 18
adult_ages = list(filter(lambda x: x >= 18, numbers))
print(adult_ages)  # Output: [20, 25, 30]

```

## Using `None` to remove Falsy Values
If you pass `None` as the first argument, Python defaults to an identity function. It will automatically strip out all **falsy values** (like `0`, `False`, empty strings `""`, or `None`).

```run-python
mixed_data = [1, 0, "apple", "", False, "orange", None]

# Filter out falsy items
clean_data = list(filter(None, mixed_data))
print(clean_data)  # Output: [1, 'apple', 'orange']
```

# Deep map

Deep map uses recursion to apply the function to nested lists 

```run-python
def deepmap(f, seq):
    if not seq:
        return []
    elif type(seq[0]) == list:
        return [deepmap(f, seq[0])] + deepmap(f, seq[1:])
    else:
        return [f(seq[0])] + deepmap(f, seq[1:])
        
lst = [1,2,[3,4],5,[6,7,8]]

def f(x):
	return x**2
	
print(deepmap(f,lst))
```

# Flatten

Function returns a new list without nesting when given a nested list

```run-python
def flatten(seq):
    if not seq:
        return []
    elif type(seq[0]) == list:
        return flatten(seq[0]) + flatten(seq[1:])
    else:
        return [seq[0]] + flatten(seq[1:])

lst = [1,2,[3,4],5,[6,7,8]]

def f(x):
	return x**2
	
print(flatten(lst))
```
