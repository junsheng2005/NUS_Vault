# Basic data types

Python has eight built-in data types. Four of those are quite simple, in the sense that they can **store a single value**:

* Integers - **int** - Natural numbers which can be counted.
```python
1,2,3
```
* Floats - **float** - Decimal numbers
```python
1.1,2.5,3.0
```
* [[1. Basic Data Types#Logical Operations|Booleans ]]- **bool** - True/False
```python
True,False
```
* [[1. Basic Data Types#Operations on Strings|Strings]] - **str** - Text. Ordered sequence of characters.
```python
"Hello World",'Hello','Bob'
```


The other four are denoted **collections** because they can **store arbitrary numbers of values**. Python's four collection data types are:

* [[4. Collections (Part I)#List|Lists]] 
```python
['apple','orange','pear']
```
* [[4. Collections (Part I)#Tuple|Tuples]]
```python
('James',"Tom","Jerry")
```
* [[Sets]]
```python
{1,2,3,'seven'}
```
* [[Dictionaries]]
```python
{'name':'John','age':18,"height":1.75}
```

## Points to remember while creating variables:

- Everything in Python is case-sensitive: 'YOU', 'you', 'You', and 'yOu' are all different names in Python
- A variable name must not start with a number. Names you define must start with a letter (a-z,A-Z) or underscore ( \_ ) and can be followed by any number of letters, digits (0-9), or underscores
- There should not be any space in a variable name.
- Do not use Python reserved keywords as variable name.
- Note that '-', '+', '*', and '/' are used by Python for defining operations on data and cannot be used in names. 
- Note also that that the characters '@', '$' and '?' are not used in Python syntax.

## Or Operator

The `or` operator returns `True` if at least one of the conditions is true. It only returns `False` if all conditions are false

```run-python
print(6 == 6 or 7 > 2)
#True,True, returns True

print(6 < 3 or 'apple' == 'apple')
#False,True, returns True

x = 6
y = 9

print(x/y > y/x or x == y or y**2 > x)
#False,False,True, returns True 

print(y == x or x >= y)
#False, False, returns False
```

## And Operator

The `and` operator returns `True` only if all expressions evaluate to `True` otherwise it evaluates to `False`

```run-python
print(6 == 6 and 7 > 2)
#True,True, returns True

print(6 < 3 and 'apple' == 'apple')
#False,True, returns False

x = 6
y = 9

print(x/y > y/x and x == y and y**2 > x)
#False,False,True, returns False 

print(y == x and x >= y)
#False, False, returns False
```

## Not Operator

The `not` operator inverts the truth value of a Boolean expression or object

```run-python
print(not True)

print(not False)
```

## Indexing of Strings
**String indexing** is the process of accessing individual characters within a string based on their specific positional numbers, known as indices.  The very first character of the string is located at index `0`

When looking at a string like `"Python"`, every character (including spaces and punctuation) maps directly to a numerical index:

| Character          | P    | y    | t    | h    | o    | n    |     |
| ------------------ | ---- | ---- | ---- | ---- | ---- | ---- | --- |
| **Positive Index** | `0`  | `1`  | `2`  | `3`  | `4`  | `5`  |     |
| **Negative Index** | `-6` | `-5` | `-4` | `-3` | `-2` | `-1` |     |

### Positive Indexing

Positive indexing reads a string from left to right. The position increments by 1 for each character. 

- **Syntax:** Square brackets `[]` to query an index.
- **Boundary:** The maximum index you can look up is always `length - 1`.
- **Errors:** Requesting an index equal to or greater than the length of the string triggers an error (e.g., `IndexError` in Python). 

### Negative Indexing

Python support negative indexing to read a string from right to left.

- **Last Character:** The last character is always at index `-1`.
- **Usefulness:** It allows you to quickly grab characters from the end of a long or variably-sized string without manually calculating its length first.

**Example:**

```run-python
text = "Python"
print(text[0])   # Outputs: 'P'
print(text[-1])  # Outputs: 'n'
```

## String Slicing

**String slicing in Python** is a technique used to extract a specific portion (substring) of a string by using square brackets and colons
The Slicing Syntax

The standard format for slicing a string is:  
`string[start:stop:step]` 

- **`start`**: The index where the slice begins (**inclusive**). Defaults to `0`.
- **`stop`**: The index where the slice ends (**exclusive**). Defaults to the end of the string.
- **`step`**: The increment value between characters. Defaults to

**Examples:**
```run-python
text = "Python"
# Text:   P  y  t  h  o  n
# Index:  0  1  2  3  4  5
# Index: -6 -5 -4 -3 -2 -1

print(text[1:4])  # Output: "yth" (Indices 1, 2, 3)

print(text[:4])   # Output: "Pyth" (Indices 0 to 3)

print(text[2:])   # Output: "thon" (Indices 2 to 5)

print(text[:])    # Output: "Python"

print(text[::2])  # Output: "Pto" (Every 2nd character)

print(text[-3:])  # Output: "hon" (Last 3 characters)

print(text[::-1])  # Output: "nohtyP"

print(text[-4::-1])  #Output: "tyP"

print(text[-1:-5:-1])  #Output: "noht"
```

## String Comparison

In Python, you can compare strings using **comparison operators like `==` and `!=` for exact values**, relational operators like `<` and `>` for alphabetical ordering, or specialized string methods for pattern and case handling.

Core Comparison Operators

Python evaluates string values character by character using their underlying **Unicode code point values**.

- **`==` (Equality)**: Returns `True` if two strings have the exact same characters in the exact same order.

- **`!=` (Inequality)**: Returns `True` if the strings are different.

- **`<` and `>` (Lexicographical Order)**: Evaluates alphabetical/dictionary order. Note that uppercase letters come before lowercase letters in the [[1. Basic Data Types#ASCII Table|Unicode Table]] (e.g., `"Apple" < "apple"` evaluates to `True`).

**Example:

```run-python
str1 = "apple"
str2 = "banana"

print(str1 == str2)  # False
print(str1 != str2)  # True
print(str1 < str2)   # True (because 'a' comes before 'b')
```

### Case-Insensitive Comparison

```run-python
name1 = "Strasse"
name2 = "STRASSE"

# Best practice for case-insensitive matching
if name1.casefold() == name2.casefold():
    print("The strings are identical.")
```
- Note: `.casefold()` is more aggressive and Unicode-aware compared to `.lower()`

### Substring and Partial Matching

If you do not need an exact match, Python provides built-in tools to look for partial patterns.
- **`in` operator**: Checks if a substring exists anywhere inside a larger string.
- **`.startswith()`**: Validates if a string begins with a specific pattern.
- **`.endswith()`**: Validates if a string ends with a specific pattern

```run-python
phrase = "Python programming is fun"

print("programming" in phrase)    # True
print(phrase.startswith("Py"))     # True
print(phrase.endswith("fun"))      # True

```

### `==` vs `is`

Never use the `is` operator to compare string values.

- The `==` operator checks if the **values** of the strings are equal.

- The `is` operator checks if they point to the exact **same memory address**. While Python sometimes optimizes memory by pointing identical text blocks to the same address (string interning), you cannot rely on this behavior.
