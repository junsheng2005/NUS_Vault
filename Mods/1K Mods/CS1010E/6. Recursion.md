**Recursion in Python** occurs when a function calls itself to solve smaller instances of the same problem. It serves as an elegant alternative to iterative loops (like `for` and `while` loops) by breaking a complex task into manageable, self-similar sub-problems.

## Factorial

```run-python
def factorial(n):
    # 1. Base Case (Stops the loop)
    if n <= 1:
        return 1
    
    # 2. Recursive Case (Calls itself with smaller input)
    else:
        return n * factorial(n - 1)

print(factorial(5))  # Output: 120
```

### Visualising the Call Stack

When you run `factorial(3)`, Python uses an internal memory structure called the **Call Stack**. It pushes active function instances onto the stack until it reaches the base case, then unwinds them in a Last-In, First-Out (LIFO) order:

STACK PUSHING (Going Down)         STACK UNWINDING (Returning Up)
  factorial(3)                                            3 * factorial(2) -> 3 * 2 = 6
    └── factorial(2)                                        2 * factorial(1) -> 2 * 1 = 2
          └── factorial(1)                                    Returns 1 (Base Case reached)

## Fibonacci

```run-python
def fibonacci(n):
    # Base cases: return n if it is 0 or 1
    if n <= 1:
        return n
    # Recursive case: sum the previous two terms
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)

# Example: Get the 7th Fibonacci number (0, 1, 1, 2, 3, 5, 8, 13...)
print(fibonacci(7))  # Output: 13
```

### Trace Tree

```python
               fibonacci(4)
               /          \
       fibonacci(3)      fibonacci(2)
       /          \          /        \
 fibonacci(2)  fib(1)    fib(1)      fib(0)
   /      \       |        |           |
 fib(1)  fib(0)   1        1           0

   |       |
   1       0

```

## Evaluating the Values (Bottom-Up)

To find the final answer, Python adds the returned values from the bottom of the tree upward:

1. `fib(2)` on the far left adds `fib(1) + fib(0)` → `1 + 0 = 1`.
2. `fib(3)` adds its children: `fib(2) + fib(1)` → `1 + 1 = 2`.
3. `fib(2)` on the right adds `fib(1) + fib(0)` → `1 + 0 = 1`.
4. `fib(4)` adds the results of its two main branches: `fib(3) + fib(2)` → `2 + 1 = 3`

# Recursions vs Iteration

| Feature                   | Recursion                                          | Iteration                                              |
| ------------------------- | -------------------------------------------------- | ------------------------------------------------------ |
| **Mechanism**             | Function repeatedly invokes itself.                | Uses explicit control loops (`for`, `while`).          |
| **Memory Consumption**    | High; saves memory states for every active call.   | Low; updates values within a fixed memory allocation.  |
| **Execution Performance** | Typically slower due to system call overhead.      | Generally faster and optimized for linear workloads.   |
| **Ideal Use Cases**       | Nested structures, JSON trees, directory searches. | Plain array tracking, sequential loops, counter lists. |

## Quiz 2
Given a list of n integer numbers, swap the number at index `i` (call this `x`) with the number at index `n-i-1` (call this `y`) if `i < n-i-1 and x < y`, for all valid `i`

Example: `[1,20,2,4,7,3,10]` should result in `[10,20,7,4,2,3,1]`

Write an iterative function to take in a list of integer numbers and return a new list as described above.

>[!example]- Answer
>
> ```run-python
> def swap(l):
> 	n = len(l)
> 	for i in range(0,n):
> 		if i < (n-i-1) and l[i] < l[n-i-1]:
> 			l[i], l[n-i-1] = l[n-i-1], l[i]
> 		else:
> 			continue
> 		
> 	return l
> 
> l1 = [1,20,2,4,7,3,10]
> 
> print(swap(l1))
> ```

## Quiz 4

Given a list `v` containing integer values, write an iterative function to return a list that contains the integer values in `v` that are larger than all integer values in `v` to their left, starting from the last to the first integer value in `v`

Example: v = [13,4,154,14] only has 154 and 13 being bigger than all values to their left. Thus [154,13] should be returned.

```run-python
def btl_rec(v):
    if len(v) <= 1:
        return v
    else:
        res = btl_rec(v[:-1])
        if v[-1] > res[0]:
            return [v[-1]]+res
        else:
            return res
```
