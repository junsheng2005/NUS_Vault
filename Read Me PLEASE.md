## Opening Folder as Obsidian Vault

1. Install and open Obsidian
2. Click "Open" under "Open folder as vault"
![405](./Attachments/Read%20Me-1785066778728.webp)

3. Select "NUS_Vault" (Unzip the folder first) ![427](./Attachments/Read%20Me-1785066937450.webp)
4. Click on "Trust author and enable plugins"![|446x231](./Attachments/Read%20Me-1785067153048.webp)
5. Congrats you got the vault working

## Using Git and Git Commands (Harder way but easier to update vault)

Please do not try this if you have no idea how Git and Github works

Look for me for the `Key`
### Obsidian Git Plugin Documentation
https://publish.obsidian.md/git-doc/Start+here
Follow this for set up^

The idea is to `git initialize` a new repository in an empty folder and
`git clone` the [[https://github.com/junsheng2005/NUS_Vault.git|remote repository]] into said folder.

Follow the same steps in [[Read Me PLEASE#Opening Folder as Obsidian Vault|Opening Folder as Obsidian Vault]].

You can choose to run `git pull` to pull the latest update from the repository in the command terminal or run `git pull` via the Git Plugin in the Vault
